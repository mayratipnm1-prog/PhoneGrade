Apa itu PhoneGrade?
Aplikasi lokal untuk menaksir harga jual kembali dan menilai kondisi HP bekas.

PhoneGrade membantu penjual dan pembeli memperkirakan harga jual kembali HP bekas. Model harga memakai usia pemakaian dan kesehatan baterai, sedangkan aturan kelayakan juga memeriksa kondisi layar. Setiap prediksi disertai penjelasan. Saat layanan Groq tersedia, AI menyusun penjelasan; jika tidak, aplikasi menampilkan ringkasan lokal. Hasil prediksi tersimpan di database lokal db.sqlite3. Halaman Visualisasi menampilkan grafik dari data yang tersedia.

Materi dan dataset proyek
Materi praktikum P07, P13, dan P14 yang digunakan dalam proyek ini.
  • P07, Modul 09 tentang pembelajaran mesin (Machine Learning) menjadi dasar pemilihan dataset HP bekas dan model untuk menaksir harga serta kelayakan.
  • P13, Modul 13 tentang model bahasa besar (LLM) dan AI generatif diterapkan pada Asisten Toko. Asisten menjawab pertanyaan tentang informasi PhoneGrade dengan Groq saat tersedia. Jika tidak, aplikasi mencocokkan pertanyaan dengan FAQ lokal.
  • P14, Modul 14 tentang Deployment diterapkan dengan menyimpan model terlatih dalam file .joblib dan menjalankannya melalui Django. SQLite menyimpan riwayat prediksi.
  • PhoneGrade memakai Used Phone Price Prediction Dataset dari Kaggle, yang berisi 1.000.000 baris. Nilai harga dalam INR dikalikan faktor konversi proyek Rp190 per INR untuk ditampilkan dalam rupiah.
Model dan teknologi
Komponen yang menghitung taksiran dan membantu menjelaskan hasil.
  • Regresi linear (LinearRegression) menaksir harga jual kembali berdasarkan usia pemakaian dalam bulan dan kesehatan baterai.
  • Model pohon keputusan (DecisionTreeClassifier) menilai kelayakan. Aturan PhoneGrade menetapkan status perlu servis jika layar retak, kesehatan baterai di bawah 75%, atau usia pemakaian 36 bulan atau lebih.
  • Saat layanan Groq tersedia, model bahasa membantu menjelaskan hasil prediksi, menguraikan grafik yang dipilih, dan menjawab pertanyaan di Asisten Toko. Jika layanan tidak tersedia, aplikasi memakai ringkasan atau jawaban lokal.
  • Chart.js menampilkan grafik interaktif, sedangkan SQLite menyimpan riwayat prediksi di db.sqlite3.
Bagaimana PhoneGrade memproses prediksi?
Model dilatih lebih dulu, lalu aplikasi memakai informasi HP untuk menghitung hasil.
1. Latih Model
Skrip latih_model.py melatih model harga dan kelayakan dari dataset, lalu menyimpan kedua model serta ringkasan statistik.
2. Isi Kondisi HP
Pada halaman Prediksi, masukkan nama HP, usia pemakaian, kesehatan baterai, dan kondisi layar.
3. Hitung Hasil
Django memakai model untuk menaksir harga. Model kelayakan dan aturan PhoneGrade menentukan status perangkat.
4. Simpan Riwayat
PhoneGrade menyimpan harga dan status kelayakan di tabel RiwayatPrediksi. Buka menu Riwayat untuk melihat hasil sebelumnya.
